# Ohnix Desktop

Descargas de la aplicación de escritorio de [Ohnix](https://ohnix.co): inventario, ventas y facturación electrónica para tu negocio.

## Descargar

Entra en la última versión, en [**Releases**](../../releases/latest), y baja el archivo que corresponda a tu computador:

| Sistema | Archivo |
|---|---|
| Windows 10 / 11 | `Ohnix_x.y.z_x64-setup.exe` |
| Mac con chip Apple (M1 o posterior) | `Ohnix_x.y.z_aarch64.dmg` |

## Instalar en Windows

1. Ejecuta el archivo `-setup.exe`.
2. Si Windows muestra **"Windows protegió tu PC"**, pulsa **Más información** y luego **Ejecutar de todas formas**. Es normal en versiones nuevas que aún no tienen firma de editor.
3. Abre **Ohnix** desde el menú de inicio e inicia sesión con tu cuenta.

## Instalar en Mac

1. Abre el `.dmg` y arrastra **Ohnix** a la carpeta Aplicaciones.
2. La primera vez, haz **clic derecho sobre la app → Abrir** y confirma. macOS lo pide porque la app todavía no está firmada por Apple.

## Requisitos

- Conexión a internet la primera vez, para iniciar sesión.
- Una cuenta de Ohnix. Si aún no tienes una, créala en [ohnix.co](https://ohnix.co).

## Actualizaciones

La app avisa cuando hay una versión nueva y te pregunta si quieres instalarla. No tienes que volver a descargar nada.

## Soporte

¿Algo no funciona? Escríbenos desde [ohnix.co](https://ohnix.co).
